# InteriorAI

Room-aware interior design recommendations. Upload a room photograph and get
furniture recommendations explained by a transparent scoring engine.

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
npm install
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Supabase (Postgres + RLS)
